# 杀毒软件误报申诉模板

当 Microsoft Defender、火绒、360 等把 `CfValidateFixer.exe` 判为威胁时，可使用下面的文本向厂商提交误报申诉。提交前请替换占位符：

| 占位符 | 替换为 |
|---|---|
| `<程序版本>` | 如 `v1.0.0` |
| `<SHA256>` | `CfValidateFixer.exe` 的 SHA256（`Get-FileHash .\CfValidateFixer.exe -Algorithm SHA256`） |
| `<检测名称>` | 杀软报出的威胁名称，如 `Trojan:Win32/Wacatac` |
| `<源码地址>` | 项目源码仓库 / 源码包下载地址 |
| `<联系邮箱>` | 你的联系邮箱 |

> **程序行为清单：**
>
> 1. **只读**读取浏览器 Cookie 数据库的**数量与名称**（如 `cf_clearance`），**不读取、不保存、不上传任何 Cookie 值**；

> 5. **不安装驱动、不注入进程、不修改系统内核、不常驻后台、不混淆、不加壳**；关闭窗口即退出；

## 二、英文申诉文本

> **Subject: False Positive Report — CfValidateFixer.exe (open-source Cloudflare verification diagnostic tool)**
>
> Dear Security Team,
>
> Our application **Cloudflare Fix Workshop (CfValidateFixer) <程序版本>** is being flagged as `<检测名称>`. We kindly request a review of this false positive.
>
> It is an **open-source** (GPLv3 + §7 attribution) Windows diagnostic utility that helps users troubleshoot and repair Cloudflare Turnstile "verification failed / stuck loading" issues. The source code is publicly auditable: `<源码地址>`.
>
> **Behavior summary:**
>
> 1. Reads browser cookie databases **read-only**, and only the **count and names** of cookies (e.g. `cf_clearance`). It **never reads, stores, or uploads cookie values**.
> 2. All repair actions are **reversible**: clearing Cloudflare verification cookies, flushing DNS, resyncing system time, commenting out blocking hosts entries, and disabling a dead system proxy. Cookie databases and the hosts file are **backed up before any change** and can be restored.
> 3. **Collects no user data.** It does not access passwords, browsing history, or bookmarks. Feedback is sent only when the user explicitly clicks "send" and only to the developer's mailbox.
> 4. Network access is limited to `challenges.cloudflare.com` (connectivity/latency probe) and `cloudflarestatus.com` (service status).
> 5. It does **not** install drivers, inject into processes, modify the kernel, run as a background service, obfuscate, or pack with UPX. Closing the window exits the app.
> 6. A `--safe` mode is available that performs diagnostics only and changes nothing.
>
> **File details:**
>
> - File: `CfValidateFixer.exe` (self-contained single-file .NET 9 WinForms app)
> - Version: `<程序版本>`
> - SHA256: `<SHA256>`
> - Signature: self-signed certificate (CN=Huobaolajiaoji); no commercial code-signing certificate yet
>
> This false positive blocks legitimate users from running the tool. Please review and whitelist the file. We are happy to provide the source code, full behavior documentation, or hash manifest upon request.

## 三、提交入口

| 厂商 | 提交入口 | 说明 |
|---|---|---|
| Microsoft Defender | <https://www.microsoft.com/en-us/wdsi/filesubmission> | 选择「Software developer」→ 上传 exe → 说明为误报并附上述英文文本 |
| 火绒 | <https://www.huorong.cn/>（以官网为准） | 火绒安全软件内「病毒上报」选择「误报」，或到火绒论坛「病毒上报」版块提交 |
| 360 | <https://sampleup.360.cn/> | 360 文件样本提交 / 误报申诉入口（以官网当前页面为准） |
| 其他 | 各厂商官网「误报申诉 / False Positive」页面 | 附 exe、SHA256、行为说明与源码地址 |

## 四、提交建议

- 同时附上 `CfValidateFixer.exe`、`SHA256SUMS.txt`、`SECURITY.md`、`PRIVACY.md` 与本文档。
- 明确写出**源码地址**与开源许可证，强调「可审计、无混淆、无壳」。
- 保留厂商返回的申诉编号，便于跟进；一般 1–3 个工作日有结果。
- 若使用自签名证书，说明「自签名仅用于本机测试，尚未购买商业证书」，避免被误判为伪造签名。
- 申诉通过后，可在 README 中记录各厂商的复核结果与时间。
